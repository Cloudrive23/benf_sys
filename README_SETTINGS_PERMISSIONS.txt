دفعة حماية شاشات القوائم والإعدادات

مبدأ التعديل:
- لم يتم تعديل ملفات الواجهات الكبيرة Client إلا عند الضرورة، وتم الاعتماد على حماية page.tsx حتى لا تضيع الميزات السابقة.
- تم ترك GET العامة للقوائم والثيم دون إغلاق كامل حتى لا تتعطل الشاشات التي تعتمد عليها.
- تم حماية عمليات الإضافة/التعديل/الحذف والإدارة بالصلاحيات المناسبة.

تأكد قبل النسخ من وجود الصلاحية التالية إن لم تكن موجودة:
database_constraint_messages.manage

بعد النسخ:
npm run build
npm run dev
